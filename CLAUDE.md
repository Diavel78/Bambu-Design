# Bambu-Design — working notes

3D-printable designs for a **Bambu Lab H2D + AMS**. Everything is generated by
parametric Python in `src/` — models are build outputs, the scripts are the
source of truth.

## Always deliver a zip — don't make me ask

**Any time models are generated or changed, finish by building a zip and
sending it in chat.** Do not hand over files one at a time, and do not just say
"they're in the repo."

```bash
python3 src/make_zip.py              # everything -> dist/Bambu-Design-print-files.zip
python3 src/make_zip.py --only boxes # just the drawer bins
```

Then attach the zip to the reply (SendUserFile). This is the last step of every
model change, not an extra the user has to request.

Zips are build artifacts — `dist/` is gitignored. Regenerate, never commit.

## Print files go out ready to slice

Ship **`.3mf` plates with the parts already arranged on the bed**, not loose
STLs the user has to position. `generate_drawer_boxes.py` writes these to
`models/drawer_boxes/bambu/` via `src/threemf.py`. Include the individual
`.stl`/`.step` files too, but lead with the `.3mf`.

Default printer is the **H2D** (350 x 320 x 325 mm). `--printer x1c|p1s|a1|
a1mini` re-arranges for smaller beds.

## Conventions

- **Units:** model in **millimeters** (what slicers expect). Sketches and
  drawer measurements come in **inches** — convert at the boundary, keep the
  inch numbers visible in READMEs and print lists since that's how they're
  measured.
- **Regenerate, don't hand-edit.** Change the CONFIG block at the top of a
  script and re-run. Stale outputs from a previous layout get cleared on each
  run so nothing wrong can get printed.
- **Validate before shipping.** Meshes watertight, parts inside the build
  volume, `.3mf` re-parsed after writing. A file that can't print is worse
  than no file.
- **Show the layout.** Every design change should refresh its preview PNG in
  `renders/` — a picture catches a misread sketch faster than a table does.

## Scripts

| Script | Makes |
|---|---|
| `src/generate_drawer_boxes.py` | drawer organizer bins + Bambu plates + previews |
| `src/generate_sonics_charm.py` | multi-color "sonics" charms (keychain/bag/croc) |
| `src/generate_bow.py` | named cheer bows (`--name Eden`) |
| `src/trace_bow.py` | traces the bow outline from `assets/` |
| `src/generate_sonics_svg.py` | Cricut SVG exports |
| `src/make_zip.py` | packages everything printable for delivery |

Dependencies: `pip install cadquery matplotlib trimesh shapely pillow scipy`
